# Tea Master

Tea Master is a static React/Vite app for choosing a tea type, selecting a recommended brewing vessel, scaling quantities by people count, and running an infusion timer.

## Run Locally

```bash
npm install
npm run dev
```

## Publish With GitHub Pages

1. Push this project to a GitHub repository.
2. In the GitHub repository, open **Settings -> Pages**.
3. Set **Build and deployment** to **GitHub Actions**.
4. Push to `main` or `master`, or run the **Deploy to GitHub Pages** workflow manually.

The workflow builds the static app into `dist/` and publishes only that folder to GitHub Pages.
